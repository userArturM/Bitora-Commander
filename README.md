# Bitora Commander

Русский двухпанельный файловый менеджер для Windows 10/11 x64, тема «Тёмный · Lime».

[Скачать установщик или portable](https://github.com/userArturM/Bitora-Commander/releases/latest)

## Иконка 2.1.1

Монограмма BC в стиле Dark Lime используется в интерфейсе, EXE, установщике и ярлыках приложения.

## Новый интерфейс 2.1

Команды сгруппированы в меню «Файлы», «Архивы», «Инструменты». Поиск сверху выполняется в активной папке. Ctrl+L включает редактирование пути; сегменты пути открывают родительские папки.

Справа — предпросмотр изображений и UTF-8 текста, сведения о выбранном файле, открытие и свойства. Для остальных форматов отображаются сведения и кнопка открытия внешней программой. Панель можно скрыть; при ширине окна меньше 1100 пикселей она скрывается автоматически, освобождая место файловым спискам. F3 по-прежнему открывает отдельное окно просмотра. Сетевые подключения доступны из «Инструменты» и кнопкой SFTP / FTP рядом с вкладками правой панели.

Очередь встроена под файловыми панелями и больше их не перекрывает. Она автоматически раскрывается при добавлении задач, показывает прогресс, скорость, оставшееся время, отмену и повтор. Её можно свернуть до строки статуса. Пауза очереди останавливает запуск следующих задач, а не активную передачу.

## Возможности

- Панели, вкладки, история, диски и закладки; автообновление сохраняет выделение и прокрутку.
- Копирование и перемещение с очередью, конфликтами (заменить / пропустить / сохранить оба), оценкой скорости/времени, отменой, повтором и журналом. Пауза очереди останавливает запуск следующих задач, а не текущую передачу.
- Перетаскивание (Shift — переместить), системный буфер файлов Ctrl+C/X/V, контекстное меню, пути, свойства и выбор внешнего приложения.
- Значки Windows и скрытые/системные атрибуты. Переключатель видимости в настройках.
- Просмотр изображений и UTF-8 редактор до 4 МБ, защита от внешних изменений.
- Встроенный 7-Zip 26.05: ZIP/7z/RAR как дерево папок, выборочное извлечение; создание ZIP и 7z.
- Поиск по имени, расширению, размеру, дате и тексту; сохранение условий. Текстовый поиск: UTF-8 файлы до 16 МБ; пропуски отображаются. Максимум 2000 результатов / 100 000 просмотренных объектов.
- Сравнение папок по размеру/дате или SHA-256. Выбор направлений для каждого различия, подтверждение перед заменой. Удалений при синхронизации нет.
- SFTP, FTPS и FTP: настройка подключений в диалоге и работа с сервером в правой панели, передача файлов и папок клавишей F5. Пароли защищены DPAPI текущей учётной записи Windows. Новый SSH-ключ требует подтверждения, изменённый ключ отклоняется. Для смены ключа удалите профиль и создайте заново после проверки у администратора.
- Проверка новой версии в настройках открывает официальный релиз; автоматической установки обновления нет.

## Работа с файлами

F2 — имя; F3 — просмотр; F4 — правка; F5 — копировать; F6 — переместить; F7 — папка; F8/Delete — корзина. Ctrl+T/W — вкладки; Ctrl+F — поиск; Tab — панель; Alt+Enter — свойства.

Отмена сохраняет уже завершённые файлы; незавершённый файл удаляется. При перемещении удаляется только успешно скопированный исходник. При повторе частично завершённой задачи совпадения снова разрешаются через диалог. Замена сначала создаёт копию и резервирует прежний файл. Доступные папки UNC обслуживаются файловым движком Windows.

Ссылки и junction не копируются и не архивируются. Архивы с ссылками не распаковываются; лимит распаковки 100 ГБ / 100 000 записей. Зашифрованные архивы и многотомные архивы не входят в проверенные сценарии. Сетевая панель передаёт файлы и папки без перезаписи совпадений. Поддерживается одно активное подключение. F6 для сетевых объектов и копирование между серверами не поддерживаются. FTP не шифрует трафик — приложение предупреждает перед подключением. FTPS проверяет сертификат сервера.

Portable хранит настройки, журнал и зашифрованные профили рядом с EXE. Пароли не переносятся на другую учётную запись/ПК автоматически. Не передавайте каталог данных вместе с portable без необходимости.

## Разработка и проверка

Node.js 24: `npm ci`, `npm test`, `npm start`.

На Windows подготовьте встроенный 7-Zip: `$env:RUNNER_TEMP=$env:TEMP; ./qa/prepare-7zip.ps1`. Скрипт получает официальный релиз ip7z/7zip 26.05 и проверяет SHA-256 при наличии digest в GitHub API. `npm run dist:win` создаёт установщик и portable в `release/`.

Тесты включают реальные localhost FTP/SFTP передачи, проверку SSH-ключа, ошибки ENOSPC/ECONNRESET, отмену файла 128 МБ, конфликты, очередь, сравнение и поиск. Тесты встроенного 7-Zip и RAR выполняются на Windows. Native QA проверяет исходное, упакованное, portable и установленное приложение, буфер Windows, иконки, DPAPI, watcher и выборочное извлечение 7z. Это не заменяет проверку всех внешних серверов, сетевых дисков и конфигураций Windows.

## Подпись выпуска

Для подписи владелец должен предоставить действующий сертификат издателя. В GitHub Actions предусмотрены секреты `CSC_LINK` (PFX или поддерживаемая ссылка) и `CSC_KEY_PASSWORD`. Не помещайте сертификат или пароль в исходники. Без этих секретов EXE остаются неподписанными; Windows может предупредить о неизвестном издателе. Ключи с аппаратным хранением требуют отдельной интеграции провайдера подписи.

7-Zip включается с его лицензией; исходники: https://github.com/ip7z/7zip. Приложение Bitora не связано с Total Commander, его плагины не поддерживает.

## Проверка интерфейса 2.1.2

`node qa/browser-regression.cjs` — дополнительные браузерные регрессии с тестовыми данными (требуется Playwright и его Chromium; можно указать BITORA_PLAYWRIGHT и BITORA_CHROMIUM). Проверяет 125 значков, папки, двойной щелчок, фильтрацию, конкурирующее обновление, Alt+Enter и окно 900×600. Нативные файловые операции, архивы, сеть и Windows-сборки проверяются отдельно в GitHub Actions.

## Рабочее пространство 2.2

Вкладки, активная панель, сортировка, история, колонки и размер окна восстанавливаются после запуска. Кнопка ★ рядом с адресом добавляет папку в избранное; список «История и избранное» открывает её одним выбором. Средняя кнопка мыши по папке открывает новую вкладку.

«Колонки» в каждой панели: включение полей и сброс размеров. Ширину меняйте перетаскиванием правой границы заголовка. При большой суммарной ширине доступна горизонтальная прокрутка списка.

В меню «Инструменты»:
- «Групповое переименование»: выделите локальные объекты, задайте шаблон, нажмите «Предпросмотр», проверьте список и примените. Поддерживаются {name}, {ext}, {n}, буквальная замена текста и нумерация. Конфликты и изменённые исходники блокируют применение.
- «Размеры папок»: анализ выделенных папок или текущей папки, если папки не выделены; отмена доступна в диалоге. Итог учитывает обычные вложенные файлы, пропуски отмечены.
- «Найти дубликаты»: группировка по размеру и SHA-256 в текущей локальной папке с подпапками. Чекбоксы изначально пустые. Перед корзиной приложение повторно проверяет файлы и требует оставить одну копию в группе.
- «Диагностика»: экспорт последних 100 ошибок и сведений о версии/системе. Журнал ограничен по размеру. Отчёт может содержать пути из сообщений ошибок; содержимое файлов и поля паролей не собираются.

Для сервера: подключитесь через «SFTP / FTP», нажмите «Открыть сервер в правой панели». Двойной щелчок открывает папки; F5 копирует выделенные объекты в другую панель. Для выхода из сетевого режима нажмите «Локальные папки». Подключение после перезапуска выполняется явно. Ссылки не передаются, совпадения не перезаписываются. При частичной ошибке уже скопированные объекты сохраняются, задача содержит сообщение об ошибке.

Анализ папок и дубликатов ограничен 250 000 объектов; групповое переименование — 5 000 объектов. Это позволяет остановить чрезмерно большой обход и выбрать более узкую папку.
