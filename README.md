# Bitora Commander

Двухпанельный файловый менеджер для Windows 10/11 x64 с русским интерфейсом «Тёмный · Lime».

[Скачать установщик и портативную версию](https://github.com/userArturM/Bitora-Commander/releases/latest)

## Возможности

- Две панели, вкладки, история папок, выбор дисков, закладки, сортировка и фильтр.
- Копирование и перемещение файлов и папок с подтверждением назначения, прогрессом и отменой. Существующие файлы не перезаписываются.
- Создание папок, переименование, удаление в системную корзину после подтверждения.
- Рекурсивный поиск по имени, просмотр изображений, просмотр и редактирование UTF-8 текста до 4 МБ с проверкой внешних изменений.
- Создание и распаковка ZIP в отдельную новую папку. Защита от выхода за пределы папки при распаковке.
- F3 просмотр, F4 редактор, F5 копирование, F6 перемещение, F7 папка, F8 корзина. Ctrl+T/W вкладки, Ctrl+F поиск, Tab переключение панели.
- Открытие доступных Windows сетевых папок через UNC-путь. Настройки сохраняются локально; portable хранит их в BitoraCommander-Data рядом с EXE.

## Ограничения первой версии

ZIP ограничен 256 МБ и 10 000 записей при распаковке; другие архивы открываются внешними приложениями. Копирование и архивирование символических ссылок/точек соединения не поддерживается. При отмене уже завершённые объекты сохраняются. Скрытие файлов относится к именам, начинающимся с точки. FTP/SFTP, плагины, синхронизация папок и встроенный терминал пока отсутствуют. Программа не является Total Commander и не связана с его разработчиками.

Установщик и portable не имеют сертификата подписи кода. Windows может показать предупреждение о неизвестном издателе.

## Разработка

Node.js 24: `npm ci`, `npm test`, `npm start`.

Windows-сборка: `npm run dist:win`. Результат в `release/`. GitHub Actions проверяет файловый движок и настоящие UI/IPC операции в исходном приложении, упакованной, портативной и установленной версиях до публикации релиза.

Используются Electron и adm-zip; приложение работает локально без сервера и аккаунта.
