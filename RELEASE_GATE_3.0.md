# Bitora Commander 3.0 — критерии и пределы проверки

## Автоматически проверяемые условия

- [x] CI Windows: `npm test`, тест всех основных диалогов, команд и горячих клавиш.
- [x] Проверки F3–F8, темы Dark Lime / Graphite / Light, размеры 900×600 и 1360×850, увеличение масштаба 125% / 150% / 200%.
- [x] Автоматическое воспроизведение обрыва сетевой передачи, повторного подключения, порчи временной копии и отказа при неверном SSH-ключе/TLS-сертификате.
- [x] Проверки зашифрованных ZIP/7z, первого тома многотомного архива, неверного пароля, отсутствующего тома, порчи и очистки временных файлов.
- [x] Имитация аварийного завершения процесса копирования, восстановление SHA-256-проверенного префикса, `fsync` файлов восстановления.
- [x] Тесты конфликтов копирования, безопасной синхронизации (в том числе изменение после сравнения), отмены и записи журналов.
- [x] Список, поиск и сортировка каталогов 10 000 / 50 000 / 100 000 файлов в Windows CI; копирование дерева из 2 001 файлов и SHA-256 сверка.
- [x] Windows GitHub Actions проверяет распакованную программу, packaged EXE, portable EXE, установку/удаление и SHA-256 дистрибутивов.
- [x] Автоматическая проверка совпадения версии в `package.json`, `package-lock.json` и release notes.

## Не покрыто доступным автоматическим окружением

- [ ] Ручные испытания на отдельных чистых пользовательских компьютерах Windows 10 и Windows 11, включая обновление поверх старой версии и проверку экранных дикторов.
- [ ] Аппаратное выключение питания, физический отказ диска, USB/SAN/SMB отключение и подтверждение долговечности данных на разных файловых системах.
- [ ] Реальные публичные FTP/FTPS/SFTP-серверы с разнообразными ошибками, тайм-аутами и инфраструктурой; в CI используются локальные тестовые FTP/SFTP-серверы и имитации.
- [ ] Исчерпывающая совместимость с закрытыми форматами защищённых и сторонних многотомных RAR и со всеми кодировками архивов.
- [ ] Независимый аудит безопасности и code signing на реальном Windows-сертификате, если не настроены секреты сертификата.

## Известные ограничения

- Встроенный 7-Zip Windows CLI получает пароль через аргумент дочернего процесса. Это временно может раскрывать пароль инструментам просмотра процессов. Bitora не сохраняет пароль в настройках.
- Сбой оборудования во время записи может повредить данные независимо от успешности синтетических CI-тестов; резервные копии важных данных по-прежнему необходимы.
- Символические ссылки и junction-папки при файловых операциях сознательно ограничены для защиты от выхода за пределы выбранных каталогов.

**Релизный вывод:** успешный CI означает проверенный автоматизированный Windows-дистрибутив. Он не подтверждает выполнение ручных и аппаратных испытаний из второго раздела и не гарантирует отсутствие всех возможных дефектов.
