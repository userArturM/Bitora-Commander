# Bitora Commander — критерии выпуска 3.0

Статус: **кандидат в разработке; версия 3.0 не должна публиковаться до выполнения условий**.

## Обязательные проверки

- [ ] Windows 10 и Windows 11: реальные испытания установщика, portable, удаления и обновления с предыдущей версии.
- [ ] Принудительное завершение процесса, отключение диска и сетевого соединения во время копирования и перемещения; проверка исходных данных, резервных копий и оставшихся временных файлов.
- [ ] Восстановление незавершённых операций после аварийного выключения с однозначным выбором источника и назначения, включая переименования, конфликты и повторное продолжение.
- [ ] Одновременные операции: пересекающиеся источники и назначения, сеть и локальные диски, пауза, отмена, повтор, отсутствие потери данных.
- [ ] SFTP, FTP, FTPS: реальные тестовые серверы, переподключение, тайм-ауты, проверка ключа SSH, безопасность хранения учётных данных.
- [ ] Синхронизация: вложенные папки, конфликтующие изменения, исключения, симлинки, безопасный просмотр плана и отмена.
- [ ] Архивы: целостность, повреждённые пути, zip-bomb ограничения, пароли, многотомные архивы, отмена и очистка временных файлов.
- [ ] Каталоги 10 000 / 50 000 / 100 000 файлов: память, скорость просмотра, виртуализация, поиск, сортировка.
- [ ] Все темы и плотности UI, масштабирование Windows 100–200%, клавиатура и доступность.
- [ ] Полный npm test + функциональные Windows-тесты исходника, installer, portable и установленного приложения; SHA-256 для обоих дистрибутивов.
- [ ] Ручной regression smoke test: F2–F8, вкладки, перенос в корзину, выбор файлов, перенос между панелями, настройки и обновление.
- [ ] Актуальная документация, список ограничений, подтверждённое отсутствие блокирующих ошибок.

Критерий приёмки: **нет известных ошибок, способных привести к необратимой потере или незаметной порче данных**; перечисленные критические сценарии подтверждены артефактами проверок, а не только компиляцией.

## Текущее состояние

CI на GitHub автоматически проверяет Windows-пакетирование и часть функциональных сценариев. Оно **не заменяет** испытания на настоящих SMB/SFTP/FTP серверах, поведение после отключения питания и ручную проверку на Windows 10/11. В частности, восстановление частичных копий имеет ограничения при переименовании назначения.
