## Bitora Commander 2.1.1 — монограмма BC

- Новая иконка BC в стиле Dark Lime: интерфейс, EXE, установщик, удаление программы и ярлыки.
- Windows ICO содержит размеры 16, 24, 32, 48, 64, 128 и 256 пикселей.
- Возможности версии 2.1 сохранены.

Windows 10/11 x64. Setup — установка; Portable — запуск без установки. EXE не подписаны сертификатом издателя.
