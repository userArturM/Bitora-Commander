# Bitora Commander 2.1.2 — папки и навигация

- Чёткие векторные значки папок и корректная обрезка длинных имён.
- Значки файлов загружаются для всей страницы, а не только первых 100 объектов.
- Выделение обновляется без пересоздания строк; двойной щелчок и предпросмотр сохраняют стабильное поведение.
- Фильтр сбрасывается при переходе в другую папку. Скрытые фильтром объекты исключены из файловых операций.
- Фоновое обновление больше не отменяет переход в другую папку; устаревшие атрибуты не применяются к новому списку.
- Alt+Enter показывает свойства без одновременного открытия файла.
- Добавлены проверки навигации мышью, фильтра и значков папок в Windows.

Windows 10/11 x64. Установщик и portable. EXE не подписаны сертификатом издателя.
