Первый выпуск Bitora Commander для Windows 10/11 x64.

Две панели и вкладки, файловые операции с подтверждением, корзина, поиск, ZIP, просмотр изображений и UTF-8 редактор. Русский интерфейс «Тёмный · Lime».

- Setup: установка с выбором папки и ярлыками.
- Portable: запуск без установки; настройки рядом с EXE.
- SHA256SUMS.txt: контрольные суммы.

Сборки не подписаны сертификатом. Ограничения первой версии перечислены в README.
