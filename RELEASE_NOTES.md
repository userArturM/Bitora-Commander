# Bitora Commander 2.8.0 — проверка архивов и исправления стабильности

- Перед распаковкой через 7-Zip выполняется тест целостности архива (`7z t`). Повреждённый архив отклоняется до публикации папки результата.
- Добавлен тест повреждённого 7z.
- Исправлена совместимость параллельной очереди с существующим интерфейсом `running`.
- Исправлена канонизация путей Windows при проверке локальной частичной копии.

В этом выпуске ещё нет UI для паролей и многотомного архивирования; это следующие подэтапы. Защищённые архивы могут требовать ввода пароля через будущий интерфейс.

Публикация EXE и portable зависит от успешного CI.
