# Bitora Commander 2.5.0 — компактное рабочее пространство

- Компактная плотность 24 px (обычная 30 / крупная 36), иконки 16 px, тонкие панели, отдельная подсветка курсора и отмеченных файлов.
- Непрерывная виртуальная прокрутка, Insert, Home/End, PageUp/PageDown, восстановление отметок клавишей / на цифровой клавиатуре. Обновление папки сохраняет курсор и отметки.
- Ctrl+M: групповое переименование; Ctrl+D: избранное; Alt+F1/F2: диски; Ctrl+Q: быстрый просмотр вместо противоположной панели; Ctrl+B: файлы подпапок; Ctrl+U: сменить папки панелей.
- Настраиваемая ширина панелей, закрепление вкладок, компактные формы, изменяемые размеры и перемещение окон инструментов, сохранение их размеров.
- Свёрнутая очередь показывает прогресс и скорость. Пауза действует на потоковые локальные, SFTP и FTP/FTPS передачи и запуск очереди; отдельные команды 7-Zip не приостанавливаются.
- Быстрое перемещение файлов внутри одного тома с эксклюзивным созданием назначения и безопасным резервным способом. Папки обходятся поэлементно.
- Просмотр больших файлов блоками по 64 КБ: UTF-8, Windows-1251, UTF-16 LE/BE, HEX. Сравнение текстов подсвечивает отличающиеся строки первых 64 КБ каждого файла. Редактор F4 сохраняет прежний безопасный режим UTF-8.
- Поиск по маскам * и ?, исключения, регулярные выражения, поиск имён внутри архивов. Обычные результаты можно вывести в панель; запись архива открывается в архивной панели.
- ZIP/7z/RAR открываются внутри файловой панели; F3 — просмотр, F5 — извлечение в противоположную папку. Копирование F5 из локальной панели добавляет файлы в открытый ZIP/7z с пересборкой архива.
- Групповое переименование: дата изменения UTC, регистр, регулярная замена, отмена последней операции в текущем сеансе с проверкой изменений файлов.
- Профили синхронизации, исключения, зеркальный выбор действий с явным списком удалений. Файлы удаляются в корзину, каталоги — только если пусты.
- Сетевое переименование, перемещение в пределах сервера и подтверждённое удаление дерева с повторной проверкой. Сетевой текстовый предпросмотр F3 через временный файл (до 16 МБ).
- Копирование между двумя серверами через локальную временную папку. Метаданные частичных передач сохраняются без паролей; после перезапуска подключитесь и повторите ту же передачу для продолжения с проверкой данных.
- Командная строка в текущей локальной папке, история 50 команд, Ctrl+Enter для имени, Ctrl+Shift+Enter для полного пути. Команды выполняются с правами пользователя; вывод ограничен последним 1 МБ.

Windows 10/11 x64. Доступны установщик, portable и SHA256SUMS.txt. Плагины Total Commander не поддерживаются.
