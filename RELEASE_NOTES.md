# Bitora Commander 2.3.0 — сетевые передачи и обновления

- Несколько независимых подключений SFTP/FTP/FTPS в сетевых вкладках. Задача копирования привязана к исходному подключению, а не к выбранной вкладке.
- Конфликты файлов: пропустить, заменить, сохранить оба, отменить; выбор можно применить ко всей задаче. Одноимённые каталоги объединяются; замена файла каталогом запрещена.
- При сетевом обрыве выполняются две попытки переподключения. Незавершённые файлы сохраняются отдельно; «Повторить» в очереди продолжает передачу после проверки уже переданных данных. Завершённый файл публикуется только после передачи. При замене прежний файл сохраняется до публикации нового.
- Настройки → «Проверить обновления» → «Скачать и проверить» → «Обновить после завершения операций». Загрузка отменяется кнопкой; размер и SHA-256 сверяются с официальным релизом.
- Установка ждёт завершения операций и очереди. Несохранённый текст по-прежнему требует решения перед выходом. После закрытия запускается установщик; portable заменяет свой EXE, сохраняет резервную копию и запускается снова.

Возобновление работает в пределах текущего запуска приложения; после перезапуска подключитесь заново. FTP/FTPS-сервер должен поддерживать REST/APPE для возобновления. Проверка префикса при FTP-скачивании может потребовать повторного чтения исходника. Закрыть подключение с незавершёнными задачами нельзя. Перенос между двумя серверами не реализован. Пароль для переподключения хранится в памяти до закрытия подключения.

Для использования встроенных обновлений сначала установите 2.3.0 вручную. Проверка контрольной суммы не заменяет подпись издателя: EXE пока не подписаны сертификатом.
