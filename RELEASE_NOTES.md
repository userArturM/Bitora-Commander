# Bitora Commander 3.0.0 — первый основной релиз

Bitora Commander 3.0 — двухпанельный файловый менеджер Windows x64 с адаптивным компактным интерфейсом, установщиком и portable-версией.

## Файловые операции
- Копирование и перемещение с очередью, параллельными независимыми задачами, приоритетами, паузой, ограничением скорости, обработкой конфликтов и SHA-256-проверкой перед заменой исходных данных.
- Восстановление локальных частичных передач после аварийного завершения процесса, журналирование с `fsync` и проверка сохранённого префикса.
- Поиск, фильтры, дубликаты, переименование, сравнение и синхронизация папок.

## Архивы, сеть, интерфейс
- Просмотр ZIP/7z/RAR; создание ZIP с AES-256 и зашифрованных 7z, разделение на тома; проверка повреждений и безопасная очистка временных данных.
- Сетевые FTP/FTPS/SFTP-сессии, подтверждение SSH-ключа, контроль целостности скачивания и загрузки и повторное подключение после временных сбоев.
- Три темы, настраиваемая панель, горячие клавиши, предпросмотр, поддержка масштабирования 125–200%, выровненные диалоги и клавиши F3–F8.

## Проверки релиза
- GitHub Actions: `npm test`, каталог 10 000 файлов, копирование 2 001 файла с проверкой SHA-256, геометрия всех диалогов и пользовательские сочетания, packaged/portable/installer, SHA-256 дистрибутивов.
- Отдельный Windows stress workflow проверяет каталоги 50 000 и 100 000 файлов; тесты имитируют разрыв сети и принудительное закрытие процесса копирования.
- Файл `qa/verify-release.cjs` проверяет согласованность версии, release notes и обязательных шагов Windows CI.

## Известные ограничения и границы тестов
- **Пароль архивов** временно доступен в параметрах дочернего 7-Zip-процесса Windows CLI; Bitora не сохраняет его в конфигурации.
- Автоматические тесты не заменяют проверку реального отключения питания, физического повреждения диска, тесты на отдельных чистых ПК Windows 10 и Windows 11 и независимый аудит безопасности.
- Не заявляется универсальная совместимость со всеми сторонними многотомными RAR или всеми сетевыми серверами.
- Цифровая подпись установщика зависит от настроенного сертификата подписи.
