# Bitora Commander 2.9.2 — защищённые и многотомные архивы

- Создание 7z с шифрованием содержимого и имён, ZIP с AES-256. Пароль передаётся 7-Zip через стандартный ввод, а не через аргументы процесса.
- Поддерживается создание многотомных ZIP/7z архивов размером тома от 1 МБ, извлечение начиная с первого тома `.001`.
- В меню «Архивы» добавлена команда создания защищённого / многотомного архива. В диалоге просмотра архива можно указать пароль для проверки и распаковки.
- Дополнительные регрессионные тесты: верный и неверный пароль, зашифрованные имена, разбиение на тома, целостность извлечения и очистка временных файлов.
- Дополнительные тесты восстановления сетевой загрузки и предварительной проверки действий синхронизации защищают существующие файлы.

## Ограничения

Некоторые виды RAR с паролями и многотомные архивы, созданные сторонними программами, требуют дополнительных совместимых тестовых образцов. Прерванное питание, физическое отключение диска и реальная Windows 10/11 ещё требуют испытаний. До полного релиза 3.0 остаются подтверждение всех критических сценариев, тестирование на чистой Windows и полный UI-аудит.
