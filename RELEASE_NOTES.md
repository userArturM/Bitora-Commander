# Bitora Commander 2.8.1 — ручная проверка архивов

- В окне просмотра архива добавлена кнопка «Проверить архив».
- Проверка запускает 7-Zip в режиме `t` и возвращает количество записей и суммарный размер распакованных данных.
- Проверка доступна отдельно от извлечения и не изменяет файлы пользователя.
- Добавлен регрессионный тест успешной проверки 7z.
- Предварительная проверка целостности перед извлечением из 2.8.0 сохранена.

Пароли и многотомное архивирование пока не добавлены. Публикация Windows EXE, portable и контрольных сумм зависит от успешного прохождения GitHub Actions.
