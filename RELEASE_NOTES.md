# Bitora Commander 2.8.5 — экспорт и импорт настроек

- В диалоге настроек доступны кнопки экспорта и импорта пользовательского оформления в JSON.
- Резервная копия имеет формат `bitora-ui-settings`, версию 1 и ограниченный список разрешённых параметров.
- Перед импортом проверяются размер файла, версия формата, тема, плотность, режим панели инструментов и доля ширины панелей.
- История пользовательских команд и секреты соединений не экспортируются.
- После импорта рабочая область перезагружается для применения оформления.
- В Windows функциональные тесты добавлена проверка формата резервной копии.

Настраиваемые горячие клавиши пока не реализованы. Выпуск EXE и portable зависит от успешного GitHub Actions.
