# Bitora Commander 2.7.4 — проверка частичных локальных копий

- Добавлен модуль `resume-local.js` для строгой проверки временной копии перед будущим возобновлением локальной передачи.
- Проверяются допустимость имени временного файла, совпадение расположения с папкой назначения, размер относительно исходника и SHA-256 переданного префикса.
- Добавлены автоматические тесты совпадающих и повреждённых префиксов, недопустимых временных путей и усечённых файлов.
- Все прежние возможности версии 2.7.3 сохранены.

**Ограничение:** это подготовительный безопасный этап. Автоматическое возобновление локального копирования после перезапуска пока не подключено к очереди и пользовательскому интерфейсу. Незавершённые копии в текущем файловом движке по-прежнему удаляются при отмене операции. Параллельные передачи пока не реализованы.

Windows 10/11 x64. GitHub Actions проверяет тесты, установщик, portable и публикует релиз только при успехе.
