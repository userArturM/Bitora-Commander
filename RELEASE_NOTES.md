# Bitora Commander 2.9.0 — обновлённый интерфейс и проверка надёжности

## Оформление и окна
- Унифицированы отступы, размеры и выравнивание верхней панели, вкладок, диалоговых окон, панели задач и клавиш F3–F8.
- Исправлено обрезание выпадающих меню из-за прокрутки верхней панели.
- Исправлено скрытие кнопки навигации после изменения порядка кнопок.
- Улучшена адаптация диалогов и таблиц при узком окне и масштабировании 125%, 150% и 200%; добавлены проверки реальной геометрии в Electron под Windows.
- GitHub Actions сохраняет скриншоты трёх тем и окна настроек как отдельный артефакт UI-Audit.

## Восстановление копирования
- Метаданные о временном файле теперь сохраняются **перед передачей данных**, чтобы после аварийного завершения процесса можно было найти частичную копию.
- По завершении успешной операции временная запись удаляется. При прерывании данные остаются для проверяемого восстановления.
- Добавлены тесты раннего прерывания, повторного продолжения и принудительного завершения отдельного процесса во время копирования с SHA-256-проверкой сохранённого префикса.

## Производительность
- В Windows CI добавлен тест каталога с 10 000 файлами.
- Отдельный Windows workflow проверяет перечисление, поиск и сортировку каталогов с 50 000 и 100 000 файлами; результаты тестов и замеры памяти публикуются в журнале Actions.
- Тесты производительности не являются гарантией одинаковой скорости на разных дисках или системах.

## Ограничения
Это **версия 2.9.0**, а не стабильный релиз 3.0.0. До полной версии остаются расширенные испытания аварийного восстановления после отключения питания, защищённые и многотомные архивы, проверки реальных сетевых отказов и ручные испытания на Windows 10/11. Успешная автоматизированная сборка не заменяет эти проверки.

Установщик Windows x64, portable и SHA256SUMS публикуются GitHub Actions только после успешного прохождения CI.
