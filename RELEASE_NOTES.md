# Bitora Commander 2.7.2 — ограничение скорости копирования

- Настраиваемый лимит локального копирования: без ограничений, 1, 5, 10, 25 или 50 МБ/с.
- Выбранная скорость сохраняется в пользовательских настройках и применяется к новым операциям F5/F6 и перетаскивания.
- Ограничение реализовано через дозирование потоковых блоков; передача по-прежнему поддерживает паузу и отмену.
- Добавлены проверки ограничения скорости, целостности и отмены ограниченной передачи.
- Сохранена проверка SHA-256 перед публикацией скопированного файла из 2.7.1.

На этом этапе лимит относится к локальным потоковым операциям; сетевые передачи, объединённая скорость нескольких задач и параллельные копирования будут развиваться отдельно. Перемещение на одном томе может выполняться без потоковой передачи.

Windows 10/11 x64. Установщик и portable публикуются после успешного тестирования GitHub Actions.
