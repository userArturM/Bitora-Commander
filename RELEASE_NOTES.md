# Bitora Commander 2.8.8 — безопасность сетевых передач

- Перед публикацией скачанного по SFTP/FTP/FTPS файла выполняется полное сравнение SHA-256 временной локальной копии и файла на сервере. Совпадения размера недостаточно.
- Перед заменой файла на сервере загруженная временная копия перечитывается и её SHA-256 сравнивается с хешем исходника.
- Если хеши не совпадают, прежнее содержимое назначения остаётся без изменений; ошибка показывается в очереди.
- Добавлен регрессионный тест симуляции повреждения сетевого потока при неизменном размере файла.
- Сохраняются улучшения очистки очереди и защиты восстановления из версии 2.8.7.

Проверка SHA-256 требует повторного чтения данных по сети, поэтому время передачи может увеличиться на медленных соединениях. Версия 3.0 всё ещё требует испытаний восстановления после аварийного отключения, паролей архивов, каталогов с 100 000 файлов и ручной проверки UI на разных масштабах Windows.

EXE и portable публикуются только после успешных тестов Windows GitHub Actions.
