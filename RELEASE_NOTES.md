## Bitora Commander 2.0.0

- Конфликты: заменить, пропустить, сохранить оба; применение решения ко всем конфликтам задачи.
- Очередь задач, скорость и оценка оставшегося времени, отмена, пауза запуска следующих задач, повтор и журнал ошибок.
- Перетаскивание, контекстное меню, Ctrl+C/X/V с системным буфером Windows, свойства и «Открыть с помощью».
- Системные иконки, скрытые/системные атрибуты, автоматическое обновление папок с сохранением выделения и прокрутки.
- Встроенный 7-Zip 26.05: просмотр ZIP/7z/RAR, создание ZIP/7z, выборочное извлечение.
- Расширенный поиск по расширению, размеру, дате и UTF-8 содержимому; сохранённые условия.
- Сравнение папок, SHA-256, выбор направлений и подтверждение перед синхронизацией. Удаления не выполняются.
- SFTP, FTPS и FTP: список файлов, загрузка/скачивание, папки и сохранённые подключения. Проверка ключа SSH, пароли в Windows DPAPI.
- Проверка обновлений из настроек, контрольные суммы релиза.

Windows 10/11 x64. Setup — установка, Portable — запуск без установки.
Без сертификата издателя сборки остаются неподписанными. Возможность подписи настроена через защищённые секреты CI; сертификат в репозиторий не помещается.
