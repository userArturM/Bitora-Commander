# Bitora Commander 2.5.1 — исправление восстановления окна

- Восстанавливаются сохранённые координаты окна после повторного запуска.
- При отключении монитора или изменении конфигурации дисплеев окно открывается в доступной области экрана.
- При первом запуске размеры окна подбираются с учётом рабочей области основного монитора.
- Все возможности версии 2.5.0 сохранены.

Windows 10/11 x64. Релиз собирается и проверяется GitHub Actions: npm test, функциональные проверки исходной, упакованной, portable и установленной версий. В случае успешного завершения публикуются установщик, portable и SHA256SUMS.txt.
