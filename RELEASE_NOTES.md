# Bitora Commander 2.7.0 — оптимизация передачи файлов

- Ограничена частота сообщений о прогрессе потокового копирования: не чаще примерно 120 мс, кроме достижения очередного 1 МБ и завершающего события.
- Уменьшена нагрузка на очередь операций и интерфейс при передаче больших файлов.
- Сохранена реакция на отмену операции по мере обработки потоковых блоков.
- Добавлен регрессионный тест для большого файла: проверяется количество событий и итоговый объём.
- Все функции управления вкладками 2.6.1 и компактный режим 2.6.0 сохранены.

Это первая часть оптимизации движка 2.7.0. Параллельное копирование и возобновление локальных передач пока не добавлены.

Windows 10/11 x64. Публикация EXE и SHA256SUMS.txt выполняется после успешного GitHub Actions.
