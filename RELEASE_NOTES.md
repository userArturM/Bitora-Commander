# Bitora Commander 2.7.1 — SHA-256 для локального копирования

- После потокового копирования локального файла выполняется сравнение SHA-256 исходника и временной копии до публикации назначения.
- При несовпадении контрольных сумм операция прекращается, временная копия удаляется и исходник сохраняется.
- При перемещении с копированием проверка SHA-256 выполняется до удаления исходного файла.
- Оптимизированные события прогресса 2.7.0 сохранены.
- Добавлен автоматический тест проверенной локальной передачи 1 МБ.

Примечание: проверка требует повторного чтения обоих файлов и может снизить скорость операций. Быстрое перемещение в пределах тома через hard-link не выполняет повторное хеширование. Дополнительные настройки скорости и параллелизма пока не реализованы.

Windows 10/11 x64. Установщик и portable публикуются после успешного GitHub Actions.
