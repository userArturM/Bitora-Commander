# Bitora Commander 2.7.6 — восстановление локальных передач

- При прерывании локального потокового копирования временные данные сохраняются, а метаданные фиксируются в пользовательском каталоге `local-recovery.json`.
- В панели очереди появился список восстановимых частичных копий, кнопки «Продолжить» и «Удалить частичную копию».
- Перед восстановлением проверяются временный путь, размер и SHA-256 записанного префикса; перед публикацией конечного файла проверяется полная SHA-256.
- Очередь запускает восстановление как обычную задачу. Исходный файл не удаляется до подтверждения целостности.
- Добавлен тест сохранения временных данных после прерывания.

Ограничения: восстановление требует доступности неизменённого исходника. Обработка восстановления ограничена локальными потоковыми передачами; сетевые операции и параллельные передачи не включены. Список восстановления не гарантирует обнаружение всех частичных файлов после аварийного выключения ПК до записи метаданных.

Windows 10/11 x64. GitHub Actions публикует установщик и portable только после успешных тестов.
