# Bitora Commander 2.6.1 — управление вкладками

- Alt+Shift+←/→ переставляет активную вкладку в файловой панели без переноса файлов.
- Активная вкладка остаётся выбранной при перестановке; новый порядок сохраняется вместе с рабочим пространством.
- Закрепление вкладок привязано к пути, а не к их позиции.
- Горячие клавиши добавлены в справку.
- Функциональный Windows-тест проверяет перестановку и сохранение активной вкладки.
- Сохранён режим максимально компактного списка 20 px из 2.6.0.

Windows 10/11 x64. Установщик, portable и SHA256SUMS.txt публикуются только после успешного завершения GitHub Actions.
