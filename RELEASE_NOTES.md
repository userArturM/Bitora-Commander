# Bitora Commander 2.7.5 — безопасное продолжение частичного копирования

- Файловый движок `transfer` поддерживает явный параметр `resumePartials` для продолжения локального копирования из временного файла.
- Перед продолжением проверяется путь временного файла, размер и SHA-256 уже записанного префикса. Новые данные добавляются только после проверки.
- После окончания дополнительно сверяется SHA-256 всей копии перед публикацией результата.
- При ошибке проверки повреждённая временная копия не публикуется и сохраняется для диагностики.
- Добавлены регрессионные тесты успешного продолжения и отказа при повреждении данных.

Ограничение: интерфейс выбора незавершённой передачи и автоматический поиск частичных копий после перезапуска пока не реализованы; новая возможность доступна через программный интерфейс движка. Обычные отменённые копии продолжают очищаться. Параллельное копирование ещё не добавлено.

Windows 10/11 x64. Установщик и portable публикуются после прохождения GitHub Actions.
